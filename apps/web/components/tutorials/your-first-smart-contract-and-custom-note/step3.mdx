Now that the counter contract is compiled, let's create the note script that calls its **`increment_count`** procedure when the Note is consumed.

Head to the <Link href="/scripts">scripts page</Link>, click the _"Create new script"_ button and enter a name, for example **counter-note** <CopyButton content="Copy Script Name" copy="counter-note" />. Then select the **Note Script** type and the **Counter Note** example.

Once your script is created, add the **counter-account** script as a dependency. The note script calls the counter contract's **`get_count`** and **`increment_count`** procedures, so it needs to import the interface of the [account component](https://docs.miden.xyz/builder/glossary/#accountcomponent) that defines them.

Click the _"Metadata"_ tab, then click the _"Add dependency"_ button. In the _"Add Dependency"_ dialog, select the **counter-account** script and click the _"Add"_ button.
