Now that both scripts are compiled, it's time to deploy the counter contract on testnet and interact with it using a Note.

When you moved on from step 2, the Playground created a **Counter Contract** account component from your **counter-account** script. Its storage layout defines a single map slot, **`counter_account::counter_contract::count_map`**, which holds the initial count, **0**, under key **1**.

Head to the <Link href="/accounts">accounts page</Link>, click the _"Create new account"_ button at the top of the page and select the _"Deploy account"_ option.

Enter a name for your contract and leave the storage mode set to **Public**. Keep **No Auth** as the authentication component: it doesn't require any signature, so anyone can make your counter contract consume an increment note. Then select the **Counter Contract** account component.

Once the component is selected, its **`counter_account::counter_contract::count_map`** storage slot is listed with its default value, **1:0**: keep it, so that the counter starts at **0**.

Finally, click the _"Deploy"_ button. This takes a few moments: the Playground creates the Account, then funds it so that it can pay transaction fees. Funding the Account is its first Transaction, which also registers it on testnet.
