Click the _"Components"_ tab of your counter contract's details page, then click the _"Invoke"_ button next to the **`get_count`** procedure to read the new value of the counter: it should have increased from **0** to **1**.

This tutorial demonstrates Miden's deployment flow:

1. **Contract building**: you compiled both the counter contract and the increment note script.
2. **Account creation**: you deployed the counter contract with its initial storage (counter value = 0). On Miden, an Account isn't deployed by a dedicated transaction: its first Transaction, which funded it here, registered it on testnet with the counter still at zero.
3. **Note publishing**: you created an increment note and published it on testnet.
4. **Note consumption**: the counter contract consumed the Note, executing the increment logic.
5. **State update**: the counter value increased and the change was recorded onchain.

Congratulations! You have successfully written, deployed and interacted with your own Miden smart contract and custom note on testnet.
