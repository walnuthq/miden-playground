Let's create the increment note by executing a Transaction that outputs a Note with your **counter-note** script.
Your wallet signs this Transaction, so make sure it's connected to the Playground before continuing.

From the <Link href="/notes">notes page</Link>, click the _"Add note"_ button and select the _"Create note"_ option.

A _"Create Note"_ dialog shows up to help you configure the note creation transaction.
Set the recipient account to the counter contract you deployed in the previous step, select the **counter-note** script and leave the note type set to **Public**. Leave the _"Network note"_ toggle off: unlike in the _"Network transactions"_ tutorial, you'll consume this Note yourself.

Don't add any note assets or note storage: the Note doesn't need to carry assets or take any parameters.

Once you're done, click the _"Create"_ button and confirm the Transaction in your wallet.

It takes some time for your Note to be committed on testnet: wait until it shows up in the notes list with the **Committed** state.
