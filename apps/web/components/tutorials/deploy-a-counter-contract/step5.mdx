Now that your account component defines both the contract's [code](https://docs.miden.xyz/reference/protocol/account/code) and its [storage](https://docs.miden.xyz/reference/protocol/account/storage) layout, it's time to deploy your counter contract on testnet.

Head to the <Link href="/accounts">accounts page</Link>, click the _"Create new account"_ button at the top of the page and select the _"Deploy account"_ option.

Enter a name for your contract and leave the storage mode set to **Public**. Keep **No Auth** as the authentication component: it doesn't require any signature, so anyone can increment the counter, just like the contract from the previous tutorial. Then select your account component, the one you created in the previous steps.

Once the component is selected, the storage slots it defines are listed with their default values, which you can override for this deployment. Keep the value you set in the previous step.

Finally, click the _"Deploy"_ button. This takes a few moments: the Playground creates the Account, then funds it so that it can pay transaction fees. Funding the Account is its first Transaction, which also registers it on testnet.
