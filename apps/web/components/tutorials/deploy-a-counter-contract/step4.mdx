An account component is made of two parts:

- Its **code**: a library of procedures that can read and write the component's storage. Here, it's the script you compiled in the previous step.
- Its **storage layout**: the list of storage slots the component uses, each with a type and an optional default value.

Your component already has its code, so let's define its storage layout. Click the _"Add storage slot"_ button and enter **`counter_contract::counter_contract::count_map`** <CopyButton content="Copy Storage Slot Name" copy="counter_contract::counter_contract::count_map" /> as the slot name. It must match the name the contract code uses to access the slot: you can find it in the **`COUNTER_SLOT`** constant of the script's _"MASM"_ tab.

Select the **Map** type, then click _"Add key-value pair"_ to set the initial value of the counter: enter **1** as the key, the fixed key used by the contract, and the initial count as the value, for example **0**.
