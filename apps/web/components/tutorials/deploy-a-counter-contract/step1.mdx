In the previous tutorial, you interacted with a counter contract that was already deployed on testnet. In this tutorial, you'll build your own counter contract, deploy it on testnet and increment its counter.

To do so, you'll write the contract code in a script, turn it into an [account component](https://docs.miden.xyz/reference/protocol/account/components) with its own storage layout, and deploy a new Account that uses this component. This gives you a foundational understanding of how custom smart contracts are developed and deployed on Miden.

Let's start by creating the script that holds the contract code. Click the _"Create new script"_ button, enter a name, then select the **Account Component** type and the **Counter Contract** example.
