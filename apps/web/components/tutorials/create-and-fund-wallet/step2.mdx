Our newly created Account was assigned an [Account ID](https://docs.miden.xyz/reference/protocol/account/id), a unique and immutable identifier. Click the link below to open your wallet:

<AccountAddress account={props.wallet} />

The ID also encodes some of the Account's metadata: its storage mode (public or private) and its version. This means the metadata can be read from the ID alone, without needing the full Account state.

Accounts can play different roles depending on the code they run. The two you'll use in this tutorial are **wallets** and **faucets**.

- **Wallets**: wallets hold assets in their vault and can send and receive them using Notes.
- **Faucets**: faucets issue (mint) new [assets](https://docs.miden.xyz/reference/protocol/asset), which can be either fungible or non-fungible.
