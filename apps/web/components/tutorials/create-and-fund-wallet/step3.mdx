To fund our wallet, we first need to execute a mint transaction on the faucet account. This Transaction creates new MDN tokens and sends them to our wallet.

A [Note](https://docs.miden.xyz/reference/protocol/note) is the medium through which Accounts communicate.
Notes hold assets and define how they can be consumed.
For instance, our mint transaction will create a Note that holds our test tokens and can only be consumed by our wallet.

From the <Link href={`/accounts/${props.faucet?.identifier}`}>faucet page</Link>, click the _"Create new transaction"_ button, then select _"New mint transaction"_. A _"Configure mint transaction"_ dialog will open, where you can select the target account (our newly created wallet) and enter an amount, e.g. **100** tokens.

The [note type](https://docs.miden.xyz/reference/protocol/note#note-type) sets the privacy of the Note you're about to create. A **public** note is stored on-chain in full, while only a commitment (hash) of a **private** note is stored on-chain and its details are shared directly with the recipient. Leave it as it is and click _"Preview"_.

The preview step summarizes the changes the Transaction will make to the executing account (in this case, the MDN Faucet).
A fungible faucet keeps track of the total supply it has minted so far in its token config [storage slot](https://docs.miden.xyz/reference/protocol/account/storage).

When you're ready, click _"Submit"_ to execute the Transaction. This can take a few moments, because a zero-knowledge proof of the Transaction has to be generated, which is computationally intensive.
