Each Note has a script that defines the conditions under which it can be consumed. Consumption of a Note can be restricted to certain Accounts or entities. For example, the **P2ID (Pay-to-ID)** note script locks a Note to a specific Account ID, so that only that Account can consume it.

The faucet created a P2ID note and wrote our wallet's Account ID into its [note storage](https://docs.miden.xyz/reference/protocol/note#storage). When the Note is consumed, its script checks that the consuming account's ID matches this one, so only our wallet can consume the Note and receive its assets.

Note storage is encoded as an array of [Felts](https://docs.miden.xyz/builder/glossary/#felt) (field elements). The decoded note storage section shows our wallet's Account ID, which is split into 2 Felts (prefix and suffix) because it doesn't fit in a single one.

Consumption happens as part of a Transaction. When a Note is consumed, its [nullifier](https://docs.miden.xyz/builder/glossary/#nullifier) is recorded on-chain, which marks the Note as spent and prevents double-spending.
