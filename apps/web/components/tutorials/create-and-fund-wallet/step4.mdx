A [Transaction](https://docs.miden.xyz/reference/protocol/transaction) in Miden is the state transition of a single Account. A Transaction takes a single Account and zero or more Notes as input, and outputs the same Account with an updated state, together with zero or more Notes.

In most blockchains, a transaction typically involves more than one account (e.g., a sender and a receiver). In Miden, a Transaction involves a single Account.

This means that minting 100 MDN tokens from a fungible faucet to a wallet takes two Transactions: one in which the faucet creates a Note containing 100 MDN, and one in which the wallet consumes that Note and receives the 100 MDN.
