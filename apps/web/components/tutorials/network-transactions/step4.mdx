Let's create the network note by executing a Transaction.
Your wallet signs this Transaction, so make sure it's connected to the Playground before continuing.

From the <Link href="/notes">notes page</Link>, click the _"Add note"_ button and select the _"Create note"_ option.

A _"Create Note"_ dialog shows up to help you configure the note creation transaction.
Set the recipient account to the network counter you deployed in step 2, select the **counter-note** script, leave the note type set to **Public** and turn on the _"Network note"_ toggle.

Don't add any note assets or note storage: the Note doesn't need to carry assets or take any parameters.

Once you're done, click the _"Create"_ button and confirm the transaction in your wallet right away. To create a network note, the Transaction reads the fee charged by the network account, which makes it expire about a minute after it's executed.

It takes some time for the network transaction builder to pick up your Note and consume it.
