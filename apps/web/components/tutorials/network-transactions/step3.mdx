Now that your network counter is registered on testnet, you'll create a public Note that the network transaction builder consumes to increment it, from **0** to **1**.

Take some time to read the <Link href="/scripts/counter-note">counter-note script</Link>. Its **`run`** procedure, at lines _23-29_, interacts with the Account that consumes the Note, here your network counter:

1. It reads the current count with the **`get_count`** procedure.
2. It calls the **`increment_count`** procedure.
3. It computes the expected count and asserts that it's equal to the new count returned by **`get_count`**.

If the contract didn't implement the increment logic correctly, the assertion would fail, and so would the Transaction consuming the Note.

A network note is a public Note that carries an attachment identifying its target network account.
Once the network transaction builder picks it up, it executes a Transaction against the target account that consumes the Note.
