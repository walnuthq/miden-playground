To complete the transfer, the output note has to be consumed by its target account.

On <Link href={`/accounts/${props.walletB.identifier}`}>Wallet B</Link>'s page, take a look at the _"Consumable Notes"_ section: the **P2ID** output note has been automatically detected as consumable by its recipient.

Click the _"Consume all notes"_ button to create a consume transaction. In this scenario there is only one consumable note, but a single Transaction can consume multiple Notes at once.

The preview dialog lets you check the asset changes about to occur. Then click _"Submit"_ to complete the transfer.
