Your send transaction has been submitted. You can inspect it by <Link href={`/transactions/${props.transaction?.id}`}>opening the first item</Link> under the _"Transactions"_ menu in the sidebar.

Notice how our MDN tokens have been placed in an output note created by the Transaction. The other output note is a TX_FEE note, which pays the transaction fee. Click the <Link href={`/notes/${props.note?.id}`}>note ID</Link> to inspect the note holding our tokens.

This output note is a **P2ID (Pay-to-ID)** note, meaning it can only be consumed by the account whose ID was written into its [note storage](https://docs.miden.xyz/reference/protocol/note#storage) when the send transaction was created.
Feel free to read the **Rust source code** of this verified note script, as well as its compiled **MASM (Miden Assembly)**, by clicking the <Link href="/scripts/p2id">script shortcut</Link>.
The script is heavily commented and provides insights into the underlying Miden architecture.

When you're done, click the target account ID in the _"Decoded Note Storage"_ section to navigate to <Link href={`/accounts/${props.walletB.identifier}`}>Wallet B</Link>.
