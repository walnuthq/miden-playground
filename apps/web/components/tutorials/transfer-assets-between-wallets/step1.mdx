import Link from "@/components/tutorials/tutorial-link";

In this tutorial, you'll learn how to transfer assets between two wallets. The Playground has already created both wallets, as well as a fungible faucet.

- <Link href={`/accounts/${props.walletA.identifier}`}>Wallet A</Link>: the
  source wallet. It has been funded with MDN tokens, and you'll transfer some
  of them to the destination wallet.
- <Link href={`/accounts/${props.walletB.identifier}`}>Wallet B</Link>: the
  destination wallet. It will receive MDN tokens from the source wallet.
- <Link href={`/accounts/${props.faucet.identifier}`}>MDN Faucet</Link>: the
  fungible faucet that issued the MDN tokens.
