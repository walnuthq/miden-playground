import { EllipsisVertical } from "lucide-react";

Now that the recipient wallet is imported, you can send it some tokens.

On the accounts page, click the <EllipsisVertical className="size-4 inline" /> icon button in your wallet's row to open the transaction menu.

Select the _"New send transaction"_ option to open the configuration modal, then select the recipient wallet as the target account and **USDCX** as the asset.

Enter a small amount, **0.001 at most**: USDCx is also the asset used to pay transaction fees on testnet, so you need to keep enough of it in your wallet to cover them. Leave the note type set to **Private**.

Click the _"Preview"_ button: Bread Wallet will ask you to confirm the send transaction, which creates a private P2ID output note carrying your tokens that only the recipient account can consume.
