In the previous tutorials, you interacted with a counter contract deployed on testnet and deployed your own. In this tutorial, you'll learn the basics of **foreign procedure invocation** (FPI) using the Miden Playground.

To demonstrate FPI, you'll deploy a **Count Reader** smart contract that reads the count of a counter contract deployed on testnet and copies it to its own storage.

FPI is a powerful tool for building composable smart contracts on Miden: it allows one smart contract or Note to read the state of another contract.

The term "foreign procedure invocation" might sound a bit verbose, but it's as simple as one smart contract calling a non-state-modifying procedure in another smart contract. The EVM equivalent of FPI would be a smart contract calling a read-only function in another contract.

FPI is useful for developing smart contracts that extend the functionality of existing contracts on Miden. It's also the core primitive used by price oracles on Miden.

To learn more, read the [Foreign Procedure Invocation](https://docs.miden.xyz/builder/tutorials/recipes/web/foreign_procedure_invocation_tutorial) tutorial in the Miden docs.
