Now that the counter contract script is compiled, let's deploy the contract on testnet.

Head to the <Link href="/accounts">accounts page</Link>, click the _"Create new account"_ button at the top of the page and select the _"Deploy account"_ option.

Enter a name for your contract and leave the storage mode set to **Public**. Keep **No Auth** as the authentication component, then select the **Counter Contract** account component and keep the default value of its **`count_map`** storage slot.

Finally, click the _"Deploy"_ button. This takes a few moments: the Playground creates the Account, then funds it so that it can pay transaction fees.

The Playground knows the source code of this contract because you deployed it from your own script.
That's why you can invoke its procedures by their names, such as **`get_count`** or **`reset_count`**, under the _"Components"_ tab of the contract's details page.

See for yourself: {props.counter ? <Link href={`/accounts/${props.counter.identifier}?tab=components`}>open the <em>"Components"</em> tab of your deployed contract</Link> : <>open the <em>"Components"</em> tab of your deployed contract</>} to list the components it contains. Click the script name next to _"Script"_ to read a component's source code.

Outside of tutorials, the Playground also verifies the contracts you deploy automatically, so that anyone can import them, read their source code and interact with them.
