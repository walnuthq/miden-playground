In the previous tutorial, you wrote your own counter contract and deployed it on testnet. In this tutorial, you'll learn what contract verification is and why it matters.

Contract verification proves that the code of a contract deployed on-chain was built from a given source code.
Once a contract is verified, anyone can read its source code, check that it does what it claims to do, and call its procedures without having to trust its author.
It's a foundation for building trust in on-chain applications.

Let's start by creating the script that holds the contract code. Click the _"Create new script"_ button, enter **{props.scriptName}** <CopyButton content="Copy Script Name" copy={props.scriptName} /> as the name, then select the **Account Component** type and the **Counter Contract** example.

Your script must be named **{props.scriptName}**: the Playground creates resources in the next steps, such as the contract's storage slot name, that expect this exact name.
The random suffix is unique to your run of this tutorial. The script name ends up in your contract's code, so nobody else will have deployed, let alone verified, the exact same contract before you.
