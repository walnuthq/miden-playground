The imported contract was built from the exact same script as the counter contract you deployed, so let's export your script to download its source code.

Head to the <Link href="/scripts">scripts page</Link>, click the <EllipsisVertical className="size-4 inline" /> icon button at the end of the **{props.scriptName}** script's row and select the _"Export script"_ option to download it.

Unzip the downloaded **{props.scriptName}.zip** archive into a folder: it contains a complete Miden project that you could also build locally.
Feel free to explore it, but don't modify any file, or you won't be able to verify the contract in the next step.
