In this tutorial, you'll use the Miden Playground to interact with a counter contract that is already deployed on testnet, and increment its count.

To do so, you'll execute a Transaction against the contract with a transaction script that calls its **`increment_count`** procedure. This gives you a foundational understanding of how to interact with custom smart contracts on Miden.

On Miden, a smart contract is an Account with custom [code](https://docs.miden.xyz/reference/protocol/account/code). This code can be written in Rust and compiled to [Miden Assembly](https://docs.miden.xyz/builder/glossary/#miden-assembly) (MASM) before being deployed on-chain.

Let's start by reading the counter contract code to understand how its **`get_count`** and **`increment_count`** procedures are implemented.
