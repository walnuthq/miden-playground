The counter contract has been imported into the Playground, so you can now interact with it.

First, click the _"Components"_ tab on the account details page to list the counter contract's [account components](https://docs.miden.xyz/reference/protocol/account/components).

Under _"Account Components"_, find the _"Counter Contract"_ component and click the _"Invoke"_ button next to the **`get_count`** procedure to read the current value of the counter. This procedure only reads storage, so the Playground executes it locally, without submitting a Transaction.

Next, click the _"Invoke"_ button next to the **`increment_count`** procedure. The Playground executes a Transaction against the counter contract with a transaction script that calls this procedure, which increments the counter by one, and submits it to testnet.

Under _"Authentication Components"_, notice that the counter contract uses the _"No Auth"_ [authentication component](https://docs.miden.xyz/reference/protocol/account/code#authentication): it doesn't require any signature, which is why anyone can increment its counter.
