The note containing your tokens must now be consumed to fund your guardian wallet.

Unlike a regular wallet, the guardian wallet can't consume the note right away. Every Transaction it executes starts as a **proposal**: a description of the state change that is sent to Miden Guardian, so it can keep track of the proposed update before co-signing it. Here, you need to create a consume note proposal.

Click the <EllipsisVertical className="size-4 inline" /> icon button in the _"Consumable Notes"_ table and select _"Consume note with …"_ to create a consume note proposal.

Approve the _"Opaque signature request"_ prompts in Bread Wallet to sign the request sent to Miden Guardian.

The note then disappears from the _"Consumable Notes"_ table, as it is now part of the consume note proposal.
