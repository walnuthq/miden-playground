Now that your note script is compiled, let's create the Note by executing a Transaction.
Your wallet signs this Transaction, so make sure it's connected to the Playground before continuing.

From the <Link href="/notes">notes page</Link>, click the _"Add note"_ button and select the _"Create note"_ option.

A _"Create Note"_ dialog shows up to help you configure the note creation transaction.
Set the recipient account to the **Test Wallet** that was created for you, select your script and leave the note type set to **Public**.

The Note is created by your wallet, so it must carry some of your assets: click the _"Add note assets"_ button, select **USDCX** as the asset and enter an amount of **1 at most**. USDCx is also the asset used to pay transaction fees on testnet, so you need to keep enough of it in your wallet to cover them.

The final step is to fill in the note storage of your custom note. Click the _"Add note storage"_ button three times to add three storage items.

The first two storage items are the target Account ID suffix and prefix: use the <Link href={`/accounts/${props.address}`}>Test Wallet</Link>'s Account ID suffix **{props.accountIdSuffix}** and prefix **{props.accountIdPrefix}**.

The third storage item is the timelock block height: you can set it to any future block height, for example **{props.syncHeight}**.

Once you're done, click the _"Create"_ button and confirm the Transaction in your wallet.
