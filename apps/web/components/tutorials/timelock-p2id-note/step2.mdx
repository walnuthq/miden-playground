You've already used **P2ID** notes in previous tutorials, but this may be the first time you look at how they're implemented.

The script starts by reading its note storage, at lines _25-33_. It contains the target [Account ID](https://docs.miden.xyz/reference/protocol/account/id), split into a suffix and a prefix: note storage items are [Felts](https://docs.miden.xyz/builder/glossary/#felt) (field elements), and an Account ID doesn't fit in a single Felt.

At lines _35-41_, the script gets the ID of the consuming account with **`account.get_id()`** and asserts that it is equal to the target Account ID, so that only the target account can consume the Note.

Finally, at lines _43-46_, it adds the note's assets to the consuming account's vault with **`receive_asset`**.
