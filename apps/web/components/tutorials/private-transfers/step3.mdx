Your Bread Wallet is funded. Before sending tokens to the Para Wallet, we need to create it and import it into the Playground.

The Playground signs Transactions with one wallet at a time, so start by disconnecting Bread Wallet: click your wallet address button in the top-right corner and select _"Disconnect"_. Your Bread Wallet stays listed on the accounts page.

Then click the _"Select Wallet"_ button and select _"Para Wallet"_. In the Para modal, enter your email address and type the verification code Para sends you by email.

Para creates a wallet for your email address and the Playground derives a **Public** Miden account from it. Once the Para Wallet appears on the <Link href="/accounts">accounts page</Link> with the **Public** storage mode, you can proceed to the next step.
