# Examples

The examples launched from the home page (`apps/web/lib/examples`) get their packages from `apps/api/examples`. Each example is a directory of MASM packages, one subdirectory per package holding its one `.masm` file (named after the package, as `sourceFilePath` names a script's), registered in `apps/api/examples/index.ts` with each package's name, kind, dependencies and hand-written schema. `POST /scripts/examples/:exampleId` creates the packages and compiles them through api-compile, in turn and each after the packages it depends on, as an import does. Later edits recompile through `PATCH /scripts/:id` as usual.

- No snapshot: a MASM build takes milliseconds, so the API compiles on launch. Measured on 2026-11-26 for the Counter Contract: 0.4 to 0.6 s per package on production's api-compile, 0.17 s for the whole launch against a local one. An SDK or api-compile bump needs nothing here: the next launch builds with it.
- An example's `ExampleMeta` can be `hidden` (`lib/examples/meta.tsx`): no card, no Projects entry, and a Mainnet or MockChain sandbox starts without the counter's packages while the Counter Contract is. Miden Bank is hidden until it's rewritten in MASM (`spec/remove-rust.md`, decision 9): it isn't in `apps/api/examples`, so launching it answers 404.
- A package's `metadata` in `index.ts` is its hand-written schema, kept while its source matches it (`lib/package-metadata.ts`, as for a template's). The Counter Contract's account uses the `counter-account` template's (`templates/counter-account.schema.ts`): the example deploys its account with the schema's slots (`useExamples`), so a lost schema deploys a counter without its storage map. `pnpm templates:check` launches every example and fails when a package doesn't compile or the account comes back without its storage schema: run it after editing an example.
- The Counter Contract's two packages started as copies of the `counter-account` and `counter-note` templates. Edit them in place; they may drift from the templates on purpose. Tutorial 9 starts from them (`counterExampleStarter`), and so do the Mainnet and MockChain sandboxes: their specs name the packages, procedures and slot (`counter_account::count_map`).
- The dev package with its debug info is what's stored and sent to the browser: the counter account is about 527 KB of base64 (395 KB of it debug info), the note 3 KB. That's about what the Rust example weighed (580 KB, mostly its note). Each launch stores it in a row and in the browser's persisted state.
- Register a new example in `apps/api/examples/index.ts` and its id in `examples/ids.ts` (plain node scripts such as `templates:check` can't import the bundled `.masm` sources), keyed by the web app's example id. The `.masm` files are bundled as strings by the Text rule in `apps/api/wrangler.jsonc`.
