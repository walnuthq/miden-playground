# Upgrading the Miden packages

When bumping `@miden-sdk/*`, also update `CLIENT_VERSION` in `apps/web/lib/utils/store.ts` to the new version. It stamps the stores the tutorials seed from `defaultStore`, and the SDK refuses to import a store stamped by a client newer than the running one. Bump the `@miden-sdk/*` pins in `pnpm-workspace.yaml` `overrides` too, regenerate the examples' compiled snapshots (see `examples.md`), and check that the script templates still compile and that the package embedded for tutorial 8 is up to date (`pnpm templates:check`, then `pnpm templates:sync` if it says so, see `script-templates.md`). Then run `pnpm masm:sync` in `apps/web` (see `masm-highlighting.md`). If the new version is younger than pnpm's minimum release age, exempt exactly that version of each package in `minimumReleaseAgeExclude`, and remove the entries once it ages out.
