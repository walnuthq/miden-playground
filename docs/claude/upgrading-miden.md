# Upgrading the Miden packages

When bumping `@miden-sdk/*`, also update `CLIENT_VERSION` in `apps/web/lib/utils/store.ts` to the new version. It stamps the stores the tutorials seed from `defaultStore`, and the SDK refuses to import a store stamped by a client newer than the running one. Bump the `@miden-sdk/*` pins in `pnpm-workspace.yaml` `overrides` too (`apps/web/lib/utils/sdk-version.test.ts` fails when the three disagree). Then regenerate the examples' compiled snapshots (see `examples.md`), and check that the script templates still compile and that the package embedded for tutorial 8 is up to date (`pnpm templates:check`, then `pnpm templates:sync` if it says so, see `script-templates.md`). Then run `pnpm masm:sync` in `apps/web` (see `masm-highlighting.md`). If the new version is younger than pnpm's minimum release age, exempt exactly that version of each package in `minimumReleaseAgeExclude`, and remove the entries once it ages out.

- Restart any running dev server after the install. Vite keeps serving the SDK it pre-bundled at startup, so the new `CLIENT_VERSION` meets the old client and every seeded store is refused ("exported by a newer client"): tutorials never start.
- The release notes list API changes only. Compare the crate versions too (`miden-client`, `miden-protocol` in the web-sdk `Cargo.toml` at both tags): a protocol bump leaves `apps/api/templates/project-template` and api-compile a version behind, so check that an example still deploys and a tutorial still runs on testnet before merging.
- Diff the skills the packages ship (`node_modules/.pnpm/@miden-sdk+miden-sdk@<old>` against `@<new>`, `skills/` and `AGENTS.md`): they document behaviour changes the notes leave out.
- Bread Wallet has to be on the same SDK minor as the playground. For a Guardian account it rebuilds a custom request (`requestTransaction` with a `CustomTransaction`: the Create Note dialog, tutorials 8, 9 and 11, the bank example) and compares it with ours byte for byte, in its own SDK's layout: 1.17.11 (SDK 0.17) refuses a request serialized by 0.18 ("Custom requests without authentication currently support only own output notes", in the extension's console only; the page just never sees the note). Check `@miden-sdk/miden-sdk` in 0xMiden/wallet's `package.json` at the latest release tag, and bump `.bread-wallet/version` (`pnpm bread-wallet latest`) with the SDK.
