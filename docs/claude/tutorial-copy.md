# Tutorial copy

Tutorial steps (`apps/web/components/tutorials`) have one wording for the desktop and the phone layout, not one per device.

- A tutorial's title, tagline, description, category, number, initial route, step count and whether it needs Bread Wallet (`requiresWallet`) live in `components/tutorials/meta.ts`, which its `index.ts` spreads (`...tutorialMeta("<id>")`): the home page and the project switcher show them from the app shell, before the SDK loads. A new tutorial gets its entry there, in order; `index.ts` checks the ids and step counts against the tutorials in dev.
- Below `lg`, the pages' create buttons ("Create new account", "Create new script", "Add note"…) and the note page's "Consume note with …" show their icon only: name them with `ButtonName` (`prose.tsx`), which shows the icon and the label. Labelled buttons and menu items take `<em>"…"</em>`.
- Refer to places outside the panel only if they hold on both layouts ("above the editor", "next to the procedure", "at the top of the page"), or link to them: on a phone the sidebar is hidden, and the panel sits at the bottom.
- "Click" is fine on both.
- A tutorial whose scripts are too big to embed in its `state` (a precompiled example's packages: a note's masp is ~560 KB) sets `starter` in its `index.ts` (`counterExampleStarter` in `lib/utils/counter-example.ts`, which the Mainnet sandbox uses too). `enterTutorial` awaits it on a fresh start and appends its scripts and components to the state's; when the API is down the tutorial opens without them, with a warning toast. Small packages are embedded instead (`lib/tutorials/counter-account.ts`, and `basic-wallet.ts` for tutorial 8, see `script-templates.md`).
- Set `requiresWallet` when a step has the user connect Bread Wallet and sign with it (tutorials 3, 4, 5, 8, 9 and 11): the first step then shows the "You need to install Bread Wallet" card while the extension is missing (`tutorial-step.tsx`). The other tutorials create their accounts in the Playground or deploy No Auth contracts, and must not show it.
